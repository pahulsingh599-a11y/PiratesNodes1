# PiratesNodes — Nodes Master Specification

This ZIP contains the Nodes Infrastructure Master Specification for PiratesNodes.

Use `PIRATESNODES_NODES_MASTER_SPEC.txt` as the build prompt/specification for the node infrastructure layer.

The specification covers:
- Multi-node infrastructure
- Node registration and secure short-lived tokens
- Node agents
- Real resource detection
- Smart node allocation
- Server provisioning
- Server splitting
- IP and port allocation
- Hostnames
- Minecraft software installation
- Jobs and retries
- Maintenance mode
- Monitoring
- Backups
- Console/file operations
- Multi-region support
- RBAC/security
- Audit logs
- API design
- GitHub Actions / build requirements
- Failure and rollback handling

Important: the specification requires real backend state and real infrastructure validation. It does not promise infinite physical RAM or arbitrary public IP generation.
